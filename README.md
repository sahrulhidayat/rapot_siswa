# Panduan Pengoperasian Aplikasi Rapot Siswa

## 1. Delete rapot_siswa.db

1. Pastikan aplikasi berhenti atau tidak sedang menjalankan koneksi ke database.
2. Hapus file rapot_siswa.db

## 2. Inisiasi Database

1. Jalankan file create_db.py
2. Periksa log atau output untuk memastikan tidak ada error.

## 3. Fitur-Fitur Setiap Menu

### Guru

- Mengakses fitur input, update, delete, dan tampilkan data guru.

### Menu Rombel

- Mengakses fitur input, update, delete, dan tampilkan data rombongan belajar.

### Menu Siswa

- Mengakses fitur input, update, delete, dan tampilkan data siswa.

### Menu Pelajaran

- Mengakses fitur input, update, delete, dan tampilkan data pelajaran.

### Menu Input Rapot

- Menambahkan atau mengupdate nilai siswa dari setiap pelajaran sesuai kelas.

### Menu Rapot Siswa

- Menampilkan seluruh nilai berdasarkan siswa yang dipilih.

## 4. Alur Penggunaan Aplikasi

1. Tambahkan Guru
2. Tambahkan Rombel
3. Tambahkan Siswa
4. Tambahkan Pelajaran
5. Input Rapot Siswa
6. Lihat Rapot Siswa
